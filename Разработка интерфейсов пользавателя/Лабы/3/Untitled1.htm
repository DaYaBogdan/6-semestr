О приложении MangaReader

MangaReader - приложение для чтения манги

Целевая аудитория: школьники, студенты, модераторы.

Основные функции:

  • Поиск по ключевым словам
  • Фильтр по тегам
  • Добавление в избранное
  • Чтение глав

Главная страница

На главной странице доступны:

  • Поле поиска по ключевым словам
  • Блок фильтрации по тегам (чекбоксы + кнопка "Применить")
  • Список карточек тайтлов

См. также:Карточка тайтла

Карточка тайтла

Содержит:

  • Обложка, название, автор, рейтинг
  • Кнопка "В избранное"
  • Кнопка "Оценить"
  • Список глав > переход в Читалку
  • Блок комментариев

Как добавить тайтл в избранное

  1. Открыть карточку тайтла
  2. Нажать кнопку "В избранное"
  3. Или использовать горячую клавишу Ctrl+D

Читалка

Элементы управления:

  • Кнопки "Предыдущая глава" / "Следующая глава"
  • Иконка "Закладка" — сохранение позиции
  • Иконка "Настройки чтения"
  • Кнопка "Оставить комментарий к главе"

Прогресс чтения сохраняется автоматически.

Профиль пользователя

Доступные разделы:

  • Редактировать профиль
  • Избранное
  • История чтения
  • Мои комментарии

Для модератора: блок жалоб и блокировок.

Избранное

Список сохранённых тайтлов. Возможности:

  • Сортировка (кнопка "Сортировать")
  • Удаление тайтла (крестик на карточке)
  • Клик по карточке > переход в карточку тайтла

Глоссарий терминов

Тайтл
— произведение (манга, комикс)
Глава
— часть тайтла
Тег
— жанр/категория
Закладка
— сохранённая позиция чтения
Комментарий
— текстовое сообщение пользователя
Жалоба
— сигнал модератору о нарушении
Модератор
— пользователь с правами управления
Блокировка
— ограничение доступа
История чтения
— список ранее открытых тайтлов
