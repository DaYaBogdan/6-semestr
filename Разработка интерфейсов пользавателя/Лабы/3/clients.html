Клиенты

На странице Клиенты ведется база данных всех клиентов салона. Здесь можно просматривать список клиентов, добавлять новых и удалять существующих.

Элементы управления

  • ◀ Предыдущая страница — переход к предыдущей странице списка клиентов
  • Следующая страница ▶ — переход к следующей странице списка клиентов
  • ➕ Добавить клиента — открытие формы для добавления нового клиента
  • 🗑️ Удалить клиента — удаление выбранного клиента из базы данных

Информация о клиенте

Карточка клиента содержит контактные данные, историю посещений, предпочтения и заметки мастеров.

См. также: Черный список (Blacklist), Запись, История посещений
